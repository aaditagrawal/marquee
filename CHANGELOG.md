# Changelog

All notable changes to Marquee are documented here. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/), and the project
uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Before 1.0.0,
minor versions may contain breaking changes.

## [Unreleased]

This is the first public source release. Before it, Marquee was developed
privately for one TV (a Sony BRAVIA VU1 on Android 11, with Jellyfin 10.11.11).
This entry describes how the public code differs from that private build. Items
marked **untested on device** have only been checked by build inspection and
host-side tests.

### Added

- **64-bit (arm64-v8a) native libraries** alongside armeabi-v7a, for Google TV
  and Android TV's 64-bit requirement (see
  [docs/RELEASE_REQUIREMENTS.md](docs/RELEASE_REQUIREMENTS.md)).
  **Untested on device**: the only test device has a 32-bit userspace.
- **Runtime device-capability detection.** The Jellyfin DeviceProfile is now
  built from the device's reported decoders (MediaCodecList) and display HDR
  capabilities, with a conservative H.264/AAC fallback if probing fails. The
  reference TV's measured profile is kept behind a narrow device gate.
  **Untested on any device other than the reference TV.**
- GPL-3.0-or-later licensing, NOTICE, third-party notices, and licence texts
  bundled in the APK under `assets/licenses/`.
- **Settings → Open-source licences.** A new last row in Settings states that
  Marquee is free software under GPL-3.0-or-later with no warranty and where
  its source is published, and opens a list of the bundled licence texts and
  third-party notices. Each opens in the existing reading sheet, loaded off the
  main thread. Before/after renders: `docs/media/settings-licences-*.png`.
  **Untested on device.**
- Documentation: architecture notes, privacy policy, security policy,
  contributing guide, Android TV requirements map and release checklist.
- CI (lint, offline unit and screenshot tests, debug and unsigned release
  builds, motion gate, benchmark-tooling tests), a manual draft-only release
  workflow, Dependabot, and issue and pull request templates.
- Generic host helpers: `tools/install-apk.sh` (needs an explicit
  `--serial` and `--apk`), `tools/device-capabilities.sh` (read-only capability
  report), `tools/check-motion.sh` and `tools/third_party_notices.py`.

### Changed
- New identity: the monochrome "reel lattice" mark replaces the gold folded M
  on the launcher icon and TV banner. A web and repository brand kit (favicons,
  lockups, social cards) is generated from the same geometry in `design/brand/`.

- **Server setup is neutral.** The sign-in screen no longer pre-fills a private
  development server address.
- **Release signing is opt-in.** `assembleRelease` produces
  `app-release-unsigned.apk` unless all four signing values are provided (see
  [README.md](README.md#build-from-source)). A partial set fails the build. The
  private build silently fell back to the debug key.
- Release APKs ship `armeabi-v7a` + `arm64-v8a`. Optional per-ABI splits are
  available. Debug APKs keep all ABIs, including x86/x86_64 for emulators.
- Versioning can be set from the command line (`-Pmarquee.versionCode`,
  `-Pmarquee.versionName`). The default is 0.2.0 (code 2).
- Release builds strip verbose, debug and info logging, which removes the
  playback timing markers. Debug and the local `profile` build keep them.
- The device name sent to Jellyfin is the name set in Android's settings (or
  the hardware model). It is no longer a fixed reference-device name.
- Lint errors now fail the build (`abortOnError`, including `lintVitalRelease`).
  Pre-existing findings are recorded in a lint baseline.
- Test fixtures and screenshot goldens are fully synthetic (generated by
  `tools/fixtures/generate.py`). No real library data is included.
- The icon generator no longer writes to, or reads from, files outside the
  repository.

### Fixed

- **No silent downgrade to `http://` after a certificate failure.** For an
  address typed without a scheme, the private build tried `http://` after any
  `https://` failure, including an untrusted certificate. The `http://` candidate
  is now tried only when HTTPS is unreachable on that address (unknown host,
  refused, timed out, or plain HTTP on that port). An untrusted, expired or
  mismatched certificate stops with a message to fix the certificate or type
  `http://` explicitly. Explicit `http://` addresses work as before, and the
  sign-in step now shows "Unencrypted connection (http)" when the resolved
  address is `http://`. Covered by `ServerProbeTest`. **Untested on device and
  against real servers.**
- **Skip Credits / Skip Intro button padding.** The focused OSD skip pill took
  on the focus ring's negative inset as view padding, so its label overflowed.
  `OsdButton.refresh()` now restores the resting padding after swapping
  backgrounds. `SkipButtonScreenshotTest` guards it. This fix shipped in the last
  private build (2026-11-08). It has not been checked on a device during a real
  credits sequence.

### Known limitations

- Tested on exactly one device (Sony BRAVIA VU1, Android 11, armeabi-v7a)
  against Jellyfin 10.11.x. Everything else is untested.
- No `MediaSession`, so system and voice media controls are not integrated.
- Jellyfin 10.11's server encoder does not preserve HDR in full video
  transcodes. Those play as SDR.
- No Android App Bundle or Google Play build. The project currently targets
  sideloading.
- The public code has not been benchmarked. The published numbers come from the
  private builds (see [docs/benchmarks/README.md](docs/benchmarks/README.md)).
